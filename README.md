# AI 輪胎原材料週報

本 repository 保存輪胎原材料週報、資料品質紀錄與採購判讀規則。

## 報告使用原則

- 僅以可追溯、具日期與規格的價格作為燈號與議價依據。
- 缺少公開現價時，一律標示「無法判定」，不以過期月均價、電商賣盤或不同品項代理指標補位。
- `參考版` 不得作為簽核或議價授權依據。

## 決策版標準

每份可決策版本必須清楚寫出：**要決定什麼、建議決定、授權上限、觸發條件、責任角色與完成期限**。沒有可驗證市場價格的品項，不製造價格燈號；改以資料治理、供應商報價或付費資料源的決策項目處理。
